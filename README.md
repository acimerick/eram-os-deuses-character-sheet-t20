# Eram os Deuses — Character Sheet T20

Versão 0.3.42 — EOD-3.5.

REV.14 — Recursos em três colunas: Vida e Mana ficam empilhadas em uma coluna esquerda deliberadamente mais estreita; Defesa ocupa a coluna central nas duas linhas; Deslocamento e Iniciativa ficam na coluna direita, empilhados.
